## 官方基线
- **v1.0.2**：官方发行版，本定制系列由此派生（英文界面、官方主题、官方音效与壁纸逻辑）。

## zh-dark36c（最新 · UI 修复测试版）

⚠️ **这是测试版，尚未在真机上验证。** 主要改动：

1. **菜单不再重叠**：游戏中先按 Home、再按关机键，不会再出现两层菜单叠在一起；关闭电源菜单后，之前的页面还能继续操作（滤镜页、按键说明页也一样）。
2. **当前滤镜用红点表示**：色彩校正里，正在使用的滤镜在名称下方显示一个居中的小红点，去掉了看不懂的星号；浏览其他滤镜时红点不会乱显示，按 A 应用成功后才更新。
3. **亮度提示更清楚**：按键说明页的亮度换成了更大的喇叭加减图标，Home + 音量键的组合意思一眼就懂。
4. **能分清测试版**：关于页会显示"实验版"标记和真正的打包日期，版本号 1.0.2-zh-dark.36c，以后不会把测试版和正式版搞混。

**没改什么：**
- 掌机里的游戏核心和系统数据用的都是官方原版，逐字节核对过，没有动。
- 没有碰存档设置区（刷完设置和壁纸位置保留）。
- 不包含任何 Chis 实体卡修复。

## zh-dark35

- **扫描线滤镜**：游戏内滤镜列表新增第 10 项「扫描线」（复古 LCD 逐行暗纹，强度固定 6/15，叠加在色彩校正之后）；FPGA 端新增 `ScanlineFilter` 模块与控制寄存器 0x1018，MCU 端新增 `set_scanline` / `configure_filter`。
- ⚠️ 本版 UF2 仍内置官方原版位流，选择「扫描线」暂无视觉效果（不会死机 / 报错），待新位流版生效。
- **渲染日志优化**：仅在单帧渲染超过 25ms 时输出日志，减少串口刷屏，轻微缓解桌面卡顿。
- **版本号 / 文档**：README 下载区更新为 .35；「回到官方发布版」说明补充 SD 卡 `official UF2` 文件夹路径。

## zh-dark34

- **壁纸列表**：去掉「关闭壁纸」项，首项改为「清空轮播列表」；进入壁纸时自动定位到当前正在轮播的那张；轮播勾选标记由 X 改为红色小圆点。
- **收藏快捷键**：由「X+A」改为「Y+A」（按住 Y 再按 A）。
- **提示音**：低音型提示音频率进一步降低（180–460 Hz），更闷沉，与清脆型区分更明显。
- **USB 读卡 / 卡带模式**：退出不再重启机器（SD 卡是否正常需实机验证）。
- **按键说明**：壁纸页说明栏改为官方图标式；新增 11 个按键图标（Y、方向、Start、Select、L、R、电源、音量）。
- **工具菜单**：新增「回到官方发布版」入口（安全引导式，不自动刷写）。
